# Harvard (Stellenbosch University): style reference for agents

Reference for citation and reference-list passes on theses that follow the Stellenbosch University (SU) flavour of Harvard. The rules are summarised from the SU Library guide "Harvard: A–Z" (https://libguides.sun.ac.za/StepbyStep/HarvardA-Z, checked 4 Nov 2026). If this summary and the guide disagree, the guide wins; if the guide is silent, keep the thesis's own consistent practice and raise a query rather than invent a form.

Some faculties allow classic Harvard instead. Use this file only when the job's instructions say the thesis follows the SU flavour.

## In-text citations

| Point | Rule | Pattern |
|---|---|---|
| Author and year | Comma between author and year inside parentheses; author outside the parentheses when part of the sentence | `(Raubenheimer, 2024)` · `Weideman (2003) claims…` |
| Page numbers | After a colon, no space, no "p." or "pp."; ranges with a hyphen | `(Weideman, 2003:111)` · `(De Visser, 2011:93-94)` |
| No page numbers | Use paragraph numbers where the source has none | `(Van Wyk, 2013:Chapter 1, para. 7)` |
| Two authors | "&" inside parentheses, "and" in running text | `(Bachman & Palmer, 1996)` · `Bachman and Palmer (1996)` |
| Three to five authors | Name all authors at the first citation, then first author + *et al.* | first: `(Davies, Brown & Smith, 1999)`; later: `(Davies et al., 1999)` |
| More than five authors | First five authors, then *et al.* | |
| *et al.* | Italic, with a full stop | `*et al.*` |
| Several works in one citation | Alphabetical by author, separated by semicolons | `(Baines, 2008; De Visser, 2011; Ramsden, 2009)` |
| Several works by one author | Years separated by commas | `Baines (2003, 2008, 2010)` |
| Same author, same year | Lower-case letter after the year, in text and list alike | `(Brown, 2005a, 2005b)` |
| Secondary citation | "cited in" (the guide also shows "quoted in" and "in"); only the source consulted goes in the list | `(Coates, cited in Lee, 1986:34)` |
| Corporate author | Abbreviation in text, full name in the list | `(SABC, 2019)` |
| No author | Title instead of author, italic if a published work | `(*Advertising in the Western Cape*, 1995:14)` |
| No date | `[s.a.]` or `[n.d.]` | `(Ross, [s.a.])` |
| Not used | *ibid.*, *op. cit.*; no access dates or DOIs in text | |

Page numbers: the guide's examples nearly always carry a page, and it asks for specific pages in the text, but it does not say that every paraphrase must have one; some of its examples have none. Direct quotations and paraphrased court judgments need pages. A pass cannot supply missing pages: raise them for the author.

## Reference list

General:
- Alphabetical by author surname; works by one author in chronological order; same author and year as 2005a, 2005b.
- Surname first, then initials: `Norback, J.S.`
- Two authors joined with "&"; three to five authors all listed.
- No author: start with the title. No date: `[s.a.]` or `[n.d.]`.
- Online sources: `[Online]. Available: URL [access date]`. The guide writes access dates as `[2013, June 17]`.
- DOI: `doi:` plus the number at the end, no full stop after it, no access date. Use the DOI instead of the URL where one exists.
- Unpublished works: title not italic, plus a descriptor (for example "Unpublished masters thesis").
- Editors: `(ed.)`/`(eds.)` in English, `(red.)`/`(reds.)` in Afrikaans.
- Corporate authors in full, without an initial "The"; a national unit with the country first: `South Africa. Department of Education.`

Patterns (italics marked with asterisks):

| Type | Pattern |
|---|---|
| Book | `Surname, I. Year. *Title: Subtitle*. 2nd edition. Place: Publisher.` |
| Edited book | `Surname, I. (ed.). Year. *Title*. Place: Publisher.` |
| Chapter in edited book | `Surname, I. Year. Chapter title, in I. Editor (ed.). *Book title*. Place: Publisher. 15-30.` |
| Journal article, print | `Surname, I. Year. Article title. *Journal Title*, 12(3):45-67.` |
| Journal article, online | `Surname, I. Year. Article title. *Journal Title* [Online], 12(3):45-67. Available: URL [2024, May 2].` (DOI form: `… 12(3):45-67. doi:10.xxxx/xxxx`) |
| Website or web page | `Surname, I. Year. *Title* [Online]. Available: URL [2016, April 19].` No author: start with the italic title. |
| Dataset or statistical release | `Statistics South Africa. 2012. *Census 2011: Statistical release* [Online]. Available: URL [2013, January 15].` |
| Report, organisation publication | `Organisation. Year. *Title* [Online]. Available: URL [access date].` |
| Act | `Republic of South Africa. Year. *Title of Act, No. x of year*. Place: Publisher.` Online: follow the online pattern; a gazette notice adds the Government Gazette number and date. |
| Thesis, unpublished | `Surname, I. Year. Title. Unpublished masters thesis. Stellenbosch: Stellenbosch University [Online]. Available: persistent link [2014, July 3].` |
| Conference paper, published | `Surname, I. & Surname, I. Year. Title, in *Proceedings title*. Place: Publisher: 215-222.` |
| Conference paper, unpublished | `Surname, I. Year. Title. Unpublished paper delivered at the Conference Name. 26 September, Place.` |
| Newspaper article | `Surname, I. Year. Article title. *Newspaper Title*, 7 October:5.` Drop "The" from the newspaper title. |
| Correspondence | `Surname, I. Year. Correspondence. 23 September, Place.` · e-mail: `Surname, I. Year. Subject, E-mail to I. Surname. 13 January.` |
| Software | `Name (computer software). Year. [Online]. Available: URL [access date].` |

The guide does not give a dedicated pattern for every report or government-publication type. Where it is silent, follow the nearest pattern above and keep the thesis consistent.

## How a pass uses this file

- Check the thesis against these rules and report each departure with its paragraph label.
- Mechanical departures (punctuation, "&" vs "and", italics, order inside a citation) are editor fixes.
- Anything that needs information from the source (page numbers, missing authors, years, a/b suffixes that change which work is meant, missing list entries) is an author query, never a guess.
- A rule that would change many places, or lengthen many sentences, goes to the editor for a ruling before it is applied thesis-wide.
